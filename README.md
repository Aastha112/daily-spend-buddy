# SpendWise

A spend tracking app built with React and Supabase.

## Tech Stack

- React
- Supabase
- shadcn-ui
- Tailwind CSS
- Vite

## Getting Started

1. **Clone the repository:**

   ```bash
   git clone https://github.com/your-username/spendwise.git
   cd spendwise
   ```

2. **Install dependencies:**

   ```bash
   npm install
   ```

3. **Set up environment variables:**

   Create a `.env` file in the root of the project and add your Supabase URL and anon key:

   ```
   VITE_SUPABASE_URL=your-supabase-url
   VITE_SUPABASE_ANON_KEY=your-supabase-anon-key
   ```

4. **Run the development server:**

   ```bash
   npm run dev
   ```

## Deploy

You can deploy this project to any static site hosting service like Netlify, Vercel, or GitHub Pages.
